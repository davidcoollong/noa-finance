💾 데이터 저장 위치
모든 데이터는 브라우저 로컬 스토리지에 저장됩니다.

• 저장 위치: 현재 기기의 브라우저
• 브라우저/기기가 달라지면 데이터가 공유되지 않습니다
• 브라우저 캐시 삭제 시 데이터가 사라질 수 있습니다
🔒 보안 안내
• 로그인 세션은 브라우저 종료 시 자동 만료
• 비밀번호는 SHA-256 해시로 저장
• 각 앱에서 개별 비밀번호 변경 가능
• 기본 계정: admin / david / sooyoung
